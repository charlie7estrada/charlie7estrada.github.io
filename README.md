# Charlie Estrada - Portfolio

Personal portfolio site - projects, background, and contact.

Muted glassmorphism design with light and dark mode toggles.

🔗 **[Live Site](https://charlie7estrada.github.io)**

![Portfolio Light Mode Preview](images/previewlight.png)

![Portfolio Dark Mode Preview](images/previewdark.png)

## Built With
- HTML5 & CSS3
- Vanilla JavaScript
- Hosted on GitHub Pages
- Traffic analytics via [GoatCounter](https://www.goatcounter.com/)

## Run Locally
```bash
git clone https://github.com/charlie7estrada/charlie7estrada.github.io.git
```
Open index.html in your browser or use a live server.
